# 🌟 Project Overview

The **Credit Risk Prediction Model** is a Machine Learning application designed to predict the credit risk category of a customer.

The application provides an interactive web interface where a user enters customer information such as:

- Age
- Sex
- Job category
- Housing status
- Saving account status
- Checking account status
- Credit amount
- Loan duration
- Purpose of the credit

The trained Machine Learning model then processes these inputs and predicts whether the customer is:
