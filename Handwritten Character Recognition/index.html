How it works

  1. 01

    Upload an image

    Drop a photo or drawing of a single digit, or use the draw tool.

  2. 02

    Preprocess

    The image is converted to grayscale and resized to 28 × 28 pixels.

  3. 03

    CNN analysis

    Two convolutional blocks extract features from the pixel grid.

  4. 04

    Prediction

    A softmax over 10 classes returns the predicted digit and confidence.
