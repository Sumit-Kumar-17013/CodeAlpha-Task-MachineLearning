# 🏦 01 — Credit Risk Model

📁 **Folder:** `Credit Risk Model/`

### 🎯 Objective

The goal of this project is to develop a Machine Learning model capable of predicting **credit risk** using historical financial and demographic information.

The project demonstrates how Machine Learning can be applied to a financial classification problem.

### 🔎 Key Work

- 📥 Dataset loading
- 🧹 Data cleaning
- 🔍 Exploratory Data Analysis
- 🧩 Categorical feature handling
- 📊 Numerical feature scaling
- ⚙️ Feature preprocessing
- 🤖 Classification model development
- ⚖️ Handling class imbalance
- 🔬 Hyperparameter tuning
- 📈 Model evaluation
- 💾 Model serialization

### 🧠 Techniques Used

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- SMOTE
- GridSearchCV
- Pipeline
- ColumnTransformer
- One-Hot Encoding
- Standardization

### 📊 Evaluation

The project explores classification performance using metrics such as:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

### 💡 What I Learned

This project helped me understand:

> **How an end-to-end Machine Learning classification pipeline can be developed for a real-world financial prediction problem.**

It also gave me practical experience with **imbalanced datasets, preprocessing pipelines, model comparison, and hyperparameter optimization**.

# ❤️ 03 — Heart Disease Prediction from Medical Data

📁 **Folder:** `Heart Disease Prediction from Medical Data/`

### 🎯 Objective

The objective of this project is to develop a Machine Learning classification system that predicts the presence of heart disease based on available medical attributes.

> ⚠️ **Educational project:** This model is intended for Machine Learning learning and experimentation only. It is not a medical diagnostic system and should not be used for clinical decisions.

### 🔎 Key Work

- 📥 Dataset loading
- 🧹 Data preprocessing
- 🔍 Exploratory Data Analysis
- 📊 Feature analysis
- ⚙️ Feature preparation
- 🤖 Classification model training
- 📈 Performance evaluation
- 🔮 Prediction

### 🧠 Machine Learning Concepts

- Supervised Learning
- Binary Classification
- Feature Engineering
- Data Preprocessing
- Model Training
- Model Evaluation
- Prediction

### 💡 What I Learned

This project helped me understand how Machine Learning can be applied to **healthcare-related datasets** and how important proper preprocessing and evaluation are when dealing with prediction problems.
